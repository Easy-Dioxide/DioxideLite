# DioxideLite v1.8.0

Performance-focused native renderer update.

- Native Minecraft GUI RenderPipeline path
- LiquidGlass retained, transparent and configurable
- Performance Mode defaults to the safe path on fresh configs
- Automatic reduced-effects fallback when frame time rises
- Visual modules remain individually toggleable in ClickGUI
- No Skia/Skija/OpenGL UI bridge
- Main-menu background is externally replaceable
