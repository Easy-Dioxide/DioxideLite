# DioxideLite ClickGUI Themes

DioxideLite keeps the original Liquid Glass ClickGUI as the `ORIGINAL` theme. It is not replaced by the alternate theme.

## Themes

- `ORIGINAL`: the original DioxideLite settings layout and Liquid Glass material.
- `MINIMAL_POP`: the compact DioxideLite Minimal presentation.
- `SIGNATURE`: an independently implemented radial/category ClickGUI with staged panel transitions, compact dark surfaces, restrained teal accents, hover interpolation and slide-in animation.

All three themes use the same DioxideLite `BasePage` and setting widgets. Switching a theme therefore changes presentation only; settings and module state are shared.

The Signature theme is an original implementation based on high-level visual/interaction observations from a supplied reference. It does not include third-party source code, assets, branding, combat automation, anti-cheat bypasses, or other non-visual modules.
