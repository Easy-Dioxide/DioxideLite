DynamicIsland 灵动岛

顶部胶囊信息面板，实时显示客户端版本 / FPS / 延迟 / 模块开关提示，随战况呼吸。

HUD 编辑器

ClickGUI 右下角铅笔按钮进入，自由拖拽排版每个 HUD 组件，RESET / DONE 一键复位与保存。

KRS 全量内核

账户与配置

微软登录（内嵌 WebView）、Altening 会话、账户保存切换；原子化配置写入与 .config 预设管理。

三步启动

DioxideLiteNG

Fabric · Minecraft 26.3 · GPL-3.0 开源
1为 Minecraft 26.3 安装 Fabric Loader 0.19.5+，使用 Java 25（Temurin 25 LTS）。
2从 Releases 下载 jar，放入 mods 目录，用 Fabric 档位启动。
3进服后按 Right Shift 打开 ClickGUI，聊天输入 .help 查看指令，.config save/load 管理预设。
