# DioxideLite v1.7.5

本版本重点恢复 DioxideLite 原有的 Liquid Glass 视觉，同时彻底移除 Skia/Skija UI 后端。

### 核心变化

- 版本号：**1.7.5**
- 默认 ClickGUI：**ORIGINAL / Liquid Glass**
- 保留 ClickGUI 热切换
- 恢复 Harmony / Icon / Material Symbols Rounded 字体
- 恢复透明玻璃材质、边缘高光和动画层级
- HUD / Visual 模块继续走 Minecraft 原生 GuiGraphics
- 推荐配合 Sodium + ImmediatelyFast 使用
- 不再依赖 Skia / Skija / HumbleUI

详见 `docs/DioxideLite-v1.7.5-Renderer.md`。
